# 🎓 IT Programming Coursework Portfolio

Welcome to my repository showcasing a selection of programming projects and lab assignments completed during my **IT Programming** coursework at NSCC. 

> ⚠️ **Note:** This repository is an ongoing work-in-progress. It contains a curated selection of my **smaller programs and lab exercises** rather than my entire coursework history, and I will continue to add more projects over time.

## 📁 Repository Contents

### 🖥️ Client-Side Web Development
* **[Portfolio Website](./Client-Side/Portfolio-Website)**: My personal professional website featuring a custom design, integrated resume layout, and responsive mobile navigation.
* **[Airplane Tracker](./Client-Side/Airplane-Tracker)**: An interactive map application that tracks live flights originating from Canada using real-time data from the **OpenSky API** and rendering via **Leaflet.js**.
* **[Three-in-a-row Game](./Client-Side/Three-in-a-row-Game)**: A puzzle game built using vanilla JavaScript DOM manipulation that fetches game data from an external API.

### ☕ Java Application Development
* **[Java/Accounting-Reporter](./Java/Accounting-Reporter)**: A **Java Swing desktop application** that gathers user input to calculate finances for an educational institution and automatically generates a structural report.

### ⚙️ C++ Application Development
* **[C++ Conversion Utility](./C-Plus-Plus/Conversion)**: A console application that reads raw `.cpp` files and safely translates them into web-friendly, character-escaped HTML formats using Regular Expressions (Regex) and custom stream exception tracking.

## 🛠️ Tech Stack & Skills Demonstrated
* **Languages & APIs:** Java (Swing GUI), C++, JavaScript (ES6+), HTML5, CSS3, OpenSky API, Game Puzzles API
* **Libraries & Frameworks:** Leaflet.js, `<fstream>`, `<regex>`
* **Core Concepts:** Desktop GUI Development, DOM Manipulation, Responsive Web Design, Asynchronous Programming (API Fetching), Object-Oriented Programming (OOP), Custom Exception Handling, Pattern Matching
