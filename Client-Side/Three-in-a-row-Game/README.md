# 🧩 Three-In-A-Row Puzzle Game

A browser-based grid puzzle game that tests logic and problem-solving skills. 

## 🛠️ Features & Technical Highlights
* **Dynamic DOM Manipulation:** Leverages vanilla JavaScript to dynamically update the game board grid, handle player clicks, and render game states without page reloads.
* **API-Driven Puzzles:** Fetches initial game board layouts, rules, or level data from an external puzzle API.
* **State Management:** Tracks win/loss conditions, illegal moves, and grid validation entirely client-side.
