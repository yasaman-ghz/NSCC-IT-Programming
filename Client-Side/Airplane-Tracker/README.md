# ✈️ Real-Time Airplane Tracker

An interactive web application that tracks and displays live flights currently originating from Canada. 

## 🛠️ Features & Technical Highlights
* **Live API Integration:** Fetches real-time, global flight state vectors directly from the **OpenSky Network API**.
* **Interactive Map UI:** Renders dynamic flight paths and markers using the **Leaflet.js** mapping framework.
* **Custom Rotations:** Utilizes `leaflet-rotatedmarker.js` to dynamically rotate airplane icons on the map to match their actual heading/bearing.
