# 🌐 Personal Portfolio Website

A personal professional website designed to showcase my software development projects, technical skills, and professional resume. 

## 🛠️ Features & Technical Highlights
* **Responsive Layout:** Built with a custom mobile hamburger menu script (`main-hamburger.js`) and matching media queries for seamless phone/desktop scaling.
* **Resume Integration:** Directly embeds a downloadable professional resume PDF.
* **Clean Layout:** Organized using semantic HTML5 and vanilla CSS3 styling grids.
